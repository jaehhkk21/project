# LUCKY SIX

한국 로또 6/45 번호를 생성하는 반응형 웹앱입니다. 별도 라이브러리나 API 키가 필요하지 않습니다.

## 실행

```sh
cd /workspace/project
npm start
```

3000번 포트에서 실행됩니다. Node.js와 Python 3이 필요합니다.

## 테스트

```sh
npm test
```

1~5게임 생성, 최대 6개 고정 번호, 최근 30게임의 브라우저 내 기록 저장 및 복사를 지원합니다. Web Crypto 기반으로 중복 없는 번호를 생성합니다. 모든 조합의 당첨 확률은 동일하며 당첨 예측 기능은 없습니다.
